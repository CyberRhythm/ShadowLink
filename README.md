# ShadowLink 🔗

مجموعه‌ای از ابزارهای ساده و کاربردی برای مدیریت فایل از طریق تلگرام.

> 📌 این مجموعه شامل دو بخش مستقل هست که می‌تونی هر کدوم رو جداگانه نصب کنی.

---

## بخش اول — ShadowLink (تلگرام به بله) 🔗

فایل رو توی تلگرام برای ربات بفرست — ShadowLink اون رو مستقیم به بله منتقل می‌کنه.

### قبل از نصب چی نیاز داری؟

| چی | از کجا |
|---|---|
| 🔵 شناسه عددی بله | ربات `@Idbotbot` در بله |
| 🔵 توکن ربات بله | ربات `@botfather` در بله |
| ✈️ توکن ربات تلگرام | ربات `@BotFather` در تلگرام |
| ✈️ شناسه عددی تلگرام | ربات `@myidbot` در تلگرام |

### نصب آسان

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/CyberRhythm/ShadowLink/main/tg2bale.sh)
```

### چطور کار می‌کنه؟

- فایل بفرستی → دانلود می‌کنه و به بله می‌فرسته ✅
- چند فایل پشت هم → صف می‌شن و به ترتیب ارسال می‌شن ✅
- فایل `.apk` یا `.exe` → اسمشو تغییر می‌ده که بله قبول کنه ✅
- ارسال موفق → توی تلگرام با تاریخ شمسی بهت خبر می‌ده ✅
- ارسال ناموفق → با مکث افزایشی (۳/۶/۹ ثانیه) تا ۳ بار دوباره تلاش می‌کنه ✅
- **قبل از دانلود، حجم فایل رو چک می‌کنه** — اگه از سقف مجاز تلگرام (۲۰ مگابایت) بزرگ‌تر باشه، اصلاً دانلود نمی‌کنه و بهت می‌گه از بخش Tele2Server استفاده کنی. این یعنی هیچ پهنای باندی روی فایل‌هایی که قابل ارسال نیستن هدر نمی‌ره (مخصوص شرایط نت ضعیف) ✅
- در برابر محدودیت تلگرام (خطای 429) مقاومه و خودش صبر می‌کنه ✅

---

## بخش دوم — Tele2Server (مدیریت فایل) 📦

فایل یا لینک مستقیم به ربات بفرست — Tele2Server اون رو به پارت‌های RAR رمزگذاری‌شده ۲۰ مگابایتی تقسیم می‌کنه و برات می‌فرسته.

### قبل از نصب چی نیاز داری؟

**ساخت ربات تلگرام**

توی تلگرام این ربات رو سرچ کن:

```
@BotFather
```

بعد از استارت:
1. دستور `/newbot` رو بزن
2. یه اسم و یه آیدی (که به `bot` ختم بشه) انتخاب کن
3. توکن ربات رو یادداشت کن

**پیدا کردن شناسه عددی تلگرامت**

توی تلگرام این ربات رو سرچ کن:

```
@myidbot
```

استارتش بزن، شناسه عددی‌ات رو بهت میده. یادداشتش کن.

**گرفتن API_ID و API_HASH**

این دو مقدار رو از سایت رسمی تلگرام می‌گیری. مراحل رو دقیق دنبال کن:

1. برو به [my.telegram.org](https://my.telegram.org)
2. شماره تلگرامت رو با کد کشور وارد کن (مثلاً `+989123456789`)
3. کد تأییدی که تلگرام برات می‌فرسته رو وارد کن
4. روی **API development tools** کلیک کن
5. یه فرم کوچیک میاد — هر چیزی دوست داری بنویس (اسم اپ و پلتفرم مهم نیست)
6. بعد از submit، دو مقدار بهت نشون می‌ده:
   - **App api_id** ← همون `API_ID`
   - **App api_hash** ← همون `API_HASH`

این دو مقدار رو کپی کن و یادداشت کن.

> ⚠️ **خطا می‌ده؟**
> اگه موقع ورود به my.telegram.org خطا گرفتی یا صفحه لود نشد، احتمالاً IP ایران فیلتره.
> راه‌حل: برنامه رایگان **Cloudflare WARP** رو نصب کن، وصل شو، بعد دوباره امتحان کن.
>
> دانلود WARP: [one.one.one.one](https://one.one.one.one)
> (برای ویندوز، اندروید، iOS و لینوکس موجوده)

### نصب آسان

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/CyberRhythm/ShadowLink/main/tele2server.sh)
```

### چطور کار می‌کنه؟

- فایل بفرستی → ربات حجم و تعداد پارت‌ها رو نشون می‌ده ✅
- لینک مستقیم بفرستی → اطلاعات فایل رو می‌خونه و آماده می‌کنه ✅
- دکمه RAR 20MB → فایل رو به پارت‌های رمزگذاری‌شده فشرده می‌کنه و پارت‌ها رو می‌فرسته ✅
- هر آرشیو پسورد قوی رندم داره (هم محتوا، هم نام فایل‌ها رمزگذاری می‌شه) ✅
- پسورد آخر توی پیام جداگانه ارسال می‌شه ✅
- دکمه لغو داخل پیام دانلود ✅
- نصب `rar` هوشمنده: اگه روی اوبونتو از مخزن نصب نشد، نسخه رسمی rarlab رو خودکار دانلود و نصب می‌کنه ✅
- اگه فشرده‌سازی شکست بخوره، خطای واقعی RAR رو بهت نشون می‌ده (نه پیام مبهم) ✅
- فایل‌های موقت بعد از ۱۲ ساعت خودکار پاک می‌شن و در صورت خطا هم نشتی نمی‌مونن ✅

### دستورات ربات

| دستور | کار |
|---|---|
| `/start` | شروع و راهنما |
| `/queue` | وضعیت دانلودهای فعال |
| `/cancel` | لغو دانلود جاری |

### راهنمای استخراج فایل‌ها

1. همه پارت‌ها رو دانلود کن
2. توی یه پوشه کنار هم بذار
3. فایل `part1.rar` رو با **WinRAR** (ویندوز) یا **ZArchiver** (اندروید) باز کن
4. پسوردی که ربات فرستاده رو وارد کن

## رفع اشکال (Troubleshooting) 🛠

**ربات استارت نمی‌خوره؟** اول لاگ رو ببین:
```bash
journalctl -u tg2bale -n 40 --no-pager       # برای بخش اول
journalctl -u tele2server -n 40 --no-pager    # برای بخش دوم
```

| پیام خطا | معنی و راه‌حل |
|---|---|
| `[FATAL] Missing required env var: ...` | یکی از مقادیر `.env` خالیه. با گزینه «Reinstall» در منو دوباره مقادیر رو وارد کن. |
| `[FATAL] Env var ... must be an integer` | شناسه عددی یا API_ID رو اشتباه (با حروف) وارد کردی. باید فقط عدد باشه. |
| `rar binary not found` / فشرده‌سازی کار نمی‌کنه | اسکریپت خودش تلاش می‌کنه `rar` رو نصب کنه؛ اگه باز هم نشد دستی نصب کن: <br>`add-apt-repository -y multiverse && apt update && apt install -y rar unrar` |
| فایل بزرگ‌تر از ۲۰MB در بخش اول ارسال نمی‌شه | این محدودیت خود تلگرام برای ربات‌هاست، نه باگ. از بخش **Tele2Server** برای تقسیم فایل استفاده کن. |
| `my.telegram.org` باز نمی‌شه | IP ایران فیلتره — با **Cloudflare WARP** وصل شو و دوباره امتحان کن. |

> 💡 این نسخه بازنویسی‌شده‌ست: مدیریت خطای کامل، بررسی حجم قبل از دانلود (صرفه‌جویی پهنای باند)،
> تلاش مجدد هوشمند، نصب مطمئن `rar`، و اعتبارسنجی ورودی‌ها. همه‌ی منطق با تست واقعی
> (از جمله تست کامل تقسیم/استخراج RAR) تأیید شده.
